# 온라인 쇼핑몰 상세페이지 기획안 (이미지형)

> Figma 작업을 전제로 한, 이미지 중심 스크롤형 상세페이지 기획안.
> 한국형 쇼핑몰의 "긴 상세페이지(롱폼)" 패턴을 기준으로 한다.

---

## 1. 목적과 KPI

| 항목 | 내용 |
|---|---|
| 1차 목적 | 상품 구매 전환율(CVR) 상승 |
| 2차 목적 | 체류시간↑, 이탈률↓, 재방문율↑, 리뷰 도달률↑ |
| KPI | CVR, 장바구니 담기율, 스크롤 75% 도달률, 상세 → 결제 전환율 |
| 보조 지표 | 평균 체류시간, 옵션 선택 완료율, 리뷰 클릭률, 문의/QnA 클릭률 |

---

## 2. 타깃과 톤앤매너

- **타깃**: 모바일 우선 (트래픽 70%+ 모바일 가정)
- **구매 결정 단계**: "탐색 → 비교 → 확신 → 결제"
- **톤**: 사진 중심 시각 설득 → 스펙·근거(텍스트) → 후기·신뢰 → 클로징
- **카피 원칙**: 한 화면에 한 메시지, 7자 이내 헤드라인 + 보조 문구

---

## 3. 정보 구조 (IA) — 위에서 아래로 스크롤 순서

```
A. 후킹       : 메인 비주얼 + 핵심 카피 (3초 안에 "왜 사야 하는가")
B. 핵심 셀링  : 3~5개 USP를 픽토그램·이미지로
C. 상세 컷    : 디테일 사진 + 사용 시나리오
D. 스펙·소재  : 사이즈/소재/원산지/세탁(또는 카테고리별 사양)
E. 비교       : 비포&애프터 / 경쟁상품 대비 비교
F. 신뢰       : 인증, 수상, 리뷰, MD 코멘트
G. FAQ        : 자주 묻는 질문 5~7개
H. 안내       : 배송·교환·반품·고객센터
I. 클로징 CTA : 마지막 "지금 구매" 모듈
```

## 4. 섹션별 와이어프레임 가이드 (Figma용)

각 섹션은 **모바일 1080px (또는 750px) 폭, 세로 자유**로 제작.
PC에서는 가운데 정렬, 양옆 여백 자동.

### A. Hero / 후킹 섹션
- 사이즈: 1080 × 1350 (모바일 풀블리드)
- 구성: 제품 누끼/연출컷 1장 + 헤드 카피(굵게) + 서브 카피
- 카피 예: "OO 하나면 충분합니다 / 하루 한 번, 5분 루틴"
- 가이드: 텍스트는 이미지 위 30% 영역에만 배치, 모바일 안전영역 확보

### B. USP / 핵심 셀링 포인트
- 3 / 5개 카드형, 1080 × 480 반복
- 좌: 아이콘 또는 디테일 컷 / 우: 한 줄 헤드 + 두 줄 서브
- 카드 간 여백 80px, 배경 톤 교차(#FFFFFF / #F7F7F7)

### C. 상세 컷
- 풀블리드 사진 6~10장, 사이사이에 한 줄 카피
- 클로즈업 → 사용 장면 → 전체 컷 순서
- 이미지 비율 4:5 권장 (피드 친화)

### D. 스펙 / 소재 / 사양표
- 1080 × 자동, 표 형태
- 의류: 사이즈표 / 가전: 사양표 / 식품: 영양정보·원산지
- 표는 이미지 대신 **텍스트 레이어**로 — 검색·접근성 ↑

### E. 비교 / 비포애프터
- 좌우 분할 1080 × 720, 슬라이더 또는 정적 비교
- 데이터·수치 1개 이상 노출 (예: "흡수력 2.3배")

### F. 신뢰 모듈
- 리뷰 캡처 3~5장 + 별점 평균 + 누적 리뷰 수
- 인증 마크, 수상, 미디어 노출(있다면)

### G. FAQ
- 펼침/접힘 5~7문항 (Figma는 정적 목업 + 인터랙션 노트)
- "사이즈 선택 가이드", "배송 일정", "교환 가능 여부" 必

### H. 안내 (공통 푸터형)
- 배송, 교환·반품, 고객센터, 고시정보(전상법 의무)
- 텍스트만, 단조로운 디자인 OK

### I. 클로징 CTA
- "지금 구매하기" 풀블리드 버튼 + 마지막 한 컷
- 한정성 카피("오늘 자정까지 무료배송") 가능 시 효과↑

## 5. 플로팅·고정 UI

- **하단 고정 바(모바일)**: 가격 / 옵션 선택 / 장바구니 / 바로구매
- **상단 진행도 바**: 스크롤 위치 표시 (선택)
- **위로가기 버튼**: 스크롤 30% 이상 시 노출

## 6. Figma 파일 구조 제안

```
[Cover]            — 표지, 프로젝트 메타
[01. 와이어프레임] — 회색 박스 단계
[02. 비주얼 시안]  — 실 이미지 입혀진 단계
[03. 컴포넌트]     — 섹션 헤더, 카드, FAQ, 가격박스, CTA 버튼
[04. 디자인 토큰]  — 컬러, 타입, 간격, 아이콘
[05. 모바일/PC]    — 반응형 비교
[06. 핸드오프]     — 개발 전달용 (잘라낼 이미지, 텍스트 레이어 분리)
```

### 추천 컴포넌트 (Variants)
- `Section/Hero`, `Section/USP-Card`, `Section/Detail-Image`, `Section/Spec-Table`
- `Button/Primary`, `Button/Sticky-Bottom`
- `Badge/Soldout`, `Badge/New`, `Badge/Limited`
- `Review/Card`, `FAQ/Item (open|closed)`

### 디자인 토큰 (예시)
- 컬러: `brand/primary`, `brand/sub`, `text/strong|body|weak`, `bg/base|alt`
- 타입: `display/40`, `headline/28`, `body/16`, `caption/12`
- 간격: 4의 배수 스케일 (4 / 8 / 16 / 24 / 40 / 80)

## 7. 이미지 제작 가이드라인

| 항목 | 권장값 |
|---|---|
| 가로 폭 | 1080px (모바일 우선) |
| 길이 | 한 컷 1500px 이하, 전체 12,000~18,000px |
| 포맷 | JPG (사진), PNG (그래픽·투명), WebP (최적화) |
| 용량 | 컷당 300KB 이하, 전체 5MB 이하 권장 |
| 텍스트 비율 | 이미지 면적의 20% 이내 (가독성·SEO) |
| 안전여백 | 좌우 60px, 상하 80px |

> 텍스트는 가능한 한 **이미지가 아닌 실제 텍스트 레이어**로 — SEO/접근성/번역.

## 8. 콘텐츠 체크리스트

- [ ] 메인 비주얼: 3초 안에 상품·매력이 전달되는가
- [ ] USP가 3~5개로 정리되었는가 (너무 많지 않게)
- [ ] 사용 장면(라이프스타일 컷)이 1개 이상 있는가
- [ ] 사이즈/스펙이 누락 없이 들어갔는가
- [ ] 리뷰·신뢰 모듈이 상단 30% 안에 미리보기 노출되는가
- [ ] 전상법 고시정보(품명, 제조국, A/S 등)가 누락되지 않았는가
- [ ] 클로징 CTA가 명확한가
- [ ] 모바일 가독성 검증 (실제 6.1인치 화면 미리보기)
